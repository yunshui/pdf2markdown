# 需求文档 (Requirements)

## 1. 项目概述

### 1.1 项目背景
创建一个Python工具，使用大语言模型（LLM）将PDF文档转换为Markdown格式，便于后续编辑和发布。

### 1.2 项目目标
- 支持单页和多页PDF文件转换
- 保持原PDF的格式和结构
- 提供灵活的配置选项
- 完善的错误处理和重试机制
- 详细的日志记录

---

## 2. 功能需求

### 2.1 核心功能

| 功能编号 | 功能名称 | 优先级 | 状态 |
|---------|---------|--------|------|
| F-001 | PDF文件验证 | P0 | ✅ 已实现 |
| F-002 | PDF页面转图片 | P0 | ✅ 已实现 |
| F-003 | 单页PDF转换 | P0 | ✅ 已实现 |
| F-004 | 多页PDF转换 | P0 | ✅ 已实现 |
| F-005 | LLM API调用 | P0 | ✅ 已实现 |
| F-006 | 重试机制 | P1 | ✅ 已实现 |
| F-007 | 超时控制 | P1 | ✅ 已实现 |
| F-008 | 日志记录 | P1 | ✅ 已实现 |
| F-009 | 配置管理 | P2 | ✅ 已实现 |

### 2.2 功能详情

#### F-001 PDF文件验证
- 验证文件是否存在
- 验证文件扩展名是否为.pdf
- 验证PDF文件是否有效（非空、可读取）
- 获取PDF页数

#### F-002 PDF页面转图片
- 支持自定义DPI（默认200）
- 使用PyMuPDF (fitz)进行转换
- 返回PIL Image对象列表

#### F-003 单页PDF转换
- 输出单个Markdown文件
- 文件名与PDF文件名相同
- 使用配置的prompt进行转换

#### F-004 多页PDF转换
- 为每页生成独立的Markdown文件
- 生成主索引文件，包含导航链接
- 每页生成中文摘要用于导航

#### F-005 LLM API调用
- 支持OpenAI兼容API
- 支持图片输入（base64编码）
- 支持自定义模型名称
- 支持自定义prompt

#### F-006 重试机制
- 可配置重试次数（默认3次）
- 失败后等待5秒重试
- 支持超时、连接错误、HTTP错误重试

#### F-007 超时控制
- 可配置超时时间（默认60秒）
- 防止长时间等待

#### F-008 日志记录
- 按天创建日志文件
- 记录类名、行号、关键参数
- 特别记录PDF当前处理页码
- 支持不同日志级别（DEBUG、INFO、WARNING、ERROR）

#### F-009 配置管理
- JSON格式配置文件
- 支持命令行参数覆盖
- 配置项包括：模型、API、重试、路径等

## 4. 接口需求

### 4.1 命令行接口

#### 基本用法
```bash
python3 pdf2md.py <pdf_file>
```

#### 可选参数
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--config, -c` | 配置文件路径 | conf/setting.json |
| `--model` | 模型名称 | 配置文件中的值 |
| `--api-url` | API URL | 配置文件中的值 |
| `--api-key` | API密钥 | 配置文件中的值 |
| `--timeout` | 超时时间（秒） | 配置文件中的值 |
| `--max-retries` | 最大重试次数 | 配置文件中的值 |
| `--output-dir` | 输出目录 | output |
| `--validate-api` | 验证API连接 | false |
| `-v, --verbose` | 详细输出 | false |

### 4.2 配置文件接口

#### 配置文件格式 (conf/setting.json)
```json
{
  "model": {
    "name": "qwen3.5-plus",
    "api_url": "https://...",
    "api_key": "sk-...",
    "timeout": 60
  },
  "conversion": {
    "max_retries": 3,
    "single_page_prompt": "...",
    "multi_page_summary_prompt": "..."
  },
  "paths": {
    "output_dir": "output",
    "logs_dir": "logs"
  }
}
```

## 6. 约束条件

### 6.1 技术约束
- Python 3.10+
- 需要网络连接访问LLM API
- 需要有效的API密钥
- 依赖PyMuPDF、Pillow、requests等库

### 6.2 业务约束
- API调用可能产生费用
- 大型PDF处理时间较长
- 图片上传有大小限制
- 模型有token限制

### 6.3 法律约束
- 需遵守API服务条款
- 用户需自行承担API费用
- 注意文档版权问题
