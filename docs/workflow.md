## 1. 总体流程

### 1.1 系统整体流程图

```

                           │
┌──────────────────────────▼──────────────────────────────────┐
│                     解析命令行参数                             │

                           │

## 2. 单页PDF转换流程

### 2.1 流程图

```
┌─────────────────────────────────────────────────────────────┐
│                      开始: PDF文件                            │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│              验证PDF文件 (PDFProcessor)                       │
│  - 检查文件是否存在                                          │
│  - 检查文件扩展名                                            │
│  - 检查PDF有效性                                            │
└──────────────┬──────────────────────────┬───────────────────┘
               │                          │
          验证失败                      验证成功
               │                          │
               ▼                          ▼
┌──────────────────────┐  ┌──────────────────────────────────────┐
│   返回错误并退出      │  │         获取页数                      │
└──────────────────────┘  │  - page_count = 1                    │
                         └──────────────────┬───────────────────┘
                                            │
                         ┌──────────────────▼───────────────────┐
                         │      转换PDF为图片                    │
                         │  - 使用PyMuPDF渲染                   │

                         └──────────────────┬───────────────────┘
                                            │
                         ┌──────────────────▼───────────────────┐
                         │     调用LLM API                      │
                         │  - prompt: single_page_prompt        │
                         │  - images: [page_image]              │
                         │  - 带重试机制                        │
                         └──────────────────┬───────────────────┘
                                            │
                         ┌──────────────────▼───────────────────┐
                         │     提取Markdown内容                  │
                         │  - 解析API响应                      │
                         │  - 提取content字段                   │
                         └──────────────────┬───────────────────┘
                                            │
                         ┌──────────────────▼───────────────────┐
                         │     保存Markdown文件                  │
                         │  - 路径: output/document.md          │
                         │  - 编码: UTF-8                       │
                         └──────────────────┬───────────────────┘
                                            │
                         ┌──────────────────▼───────────────────┐
                         │      记录日志并返回成功                │

### 2.2 详细步骤

| 步骤 | 操作 | 输入 | 输出 | 耗时 |
|------|------|------|------|------|
| 1 | 验证PDF | PDF路径 | True/False | <1秒 |
| 2 | 获取页数 | PDF路径 | 页数(1) | <1秒 |
| 3 | 转换图片 | PDF路径, DPI | Image对象 | ~1秒 |
| 4 | 调用API | prompt, images | Markdown文本 | ~24秒 |
| 5 | 保存文件 | content, 路径 | .md文件 | <1秒 |
| **总计** | | | | **~27秒** |

### 5.3 重试计数bug修复流程

**原始错误**:
```python
# 错误的实现
max_retries = retry_count + self.max_retries if retry_count > 0 else self.max_retries
# 问题: 每次递归调用，max_retries都在增加，导致无限重试
```

**修复后**:
```python
# 正确的实现
max_retries = self.max_retries
# 固定使用配置的max_retries值
```

**修复流程**:
1. 发现问题（测试时无限重试）
2. 分析代码逻辑（理解递归重试机制）
3. 修正变量计算（使用固定值）
4. 重新测试（验证重试次数正确）

## 10. 总结

### 10.1 关键流程总结

| 流程 | 核心组件 | 关键步骤 | 耗时 |
|------|---------|---------|------|
| 单页转换 | Converter | 验证→转图→API调用→保存 | ~27秒 |
| 多页转换 | Converter | 验证→转图→循环处理→索引 | ~99秒/3页 |
| API调用 | ModelClient | 准备请求→发送→解析 | ~24秒 |
| 重试机制 | ModelClient | 检查错误→等待→递归 | +5秒/次 |

### 10.2 流程特点

1. **清晰的分层**: CLI→Converter→Processor/Client→API
2. **完善的错误处理**: 每个步骤都有错误检查和记录
3. **详细的日志记录**: 关键节点都有日志输出
4. **灵活的配置**: 支持文件和命令行两种配置方式
5. **可扩展性**: 预留了并行处理等优化空间
